# Security

Security fixes are supported on the current `main` branch. Older builds may no
longer receive fixes after the project moves to a newer Signal Desktop release.

Please do not disclose a suspected vulnerability in a public issue. If the
repository's Security tab offers **Report a vulnerability**, use that private
form. Otherwise, contact a maintainer privately before sharing technical details.
Include the affected Vesper version, operating system, impact and a minimal way
to reproduce the problem.

Do not include private keys, account credentials, message contents or other
people's personal data in a report. Test only with accounts and devices you are
authorised to use.
